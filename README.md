# 📚 ALPHA — Free Study Resource Hub

**Study Smarter. Download Faster. 🚀**

ALPHA is a free educational platform designed to help students access useful study resources in one place. Our goal is to make learning easier, faster, and more accessible for everyone.

## ✨ Features

* 📖 Study materials for Classes 10 & 12
* 📝 Notes and important questions
* 📄 Sample papers and previous year questions (PYQs)
* 📚 Syllabus and formula sheets
* 📱 Responsive and mobile-friendly interface
* 🌙 Modern dark-themed UI
* ⚓ Career awareness and Merchant Navy information
* 🆓 Free access to available educational resources

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript

## 🎯 Our Mission

To provide students with accessible educational resources that help them prepare smarter, stay organized, and achieve their academic goals.

## 🚀 Project Vision

ALPHA aims to grow into a student-focused educational platform offering learning resources, academic guidance, and useful skills for the future.
